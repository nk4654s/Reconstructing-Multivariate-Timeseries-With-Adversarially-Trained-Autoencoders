# Toking
The `Toking` package simplifies retrieving a correct access token for `IAM`. The application reads a secret value from
`AWS` secret manager, which contains login credentials for `IAM`. Using these credentials, a valid token can be
created using `AWS Secure Remote Password` protocol.

## Usage
A token for the `ai-cas@nea-x.net` can be generated by calling the following command
```Cmd
toking
```

> Note: Without configuration, the `toking` command uses its default values. To learn more about the configuration, 
> call `toking -h`.
